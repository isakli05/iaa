## 3. Machine-specific absolute paths

`CANONICAL-README.md` (+ its byte-exact pack copy) — the install-era README
whose commands recorded the original machine layout; `docs/HISTORICAL-
EVIDENCE-DISPOSITION.md` and `web-project-sources/07-*` — evidence-tree

implied by the GitHub handle `isakli05`) and directory names of local evidence.

`CANONICAL-README.md` must stay byte-exact (it mirrors the deployed historical
copy — its provenance note already labels it install-era). All *current*
documentation (README, docs/INSTALLATION, UPDATE, UNINSTALL, INVOCATION,
packaging READMEs) uses `$HOME`-relative examples exclusively — verified.
