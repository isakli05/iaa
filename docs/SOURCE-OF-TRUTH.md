# Source of Truth and File Map

## Verdict (normalized 2026-09-23, Gate 2 — supersedes the 2026-09-22 baseline model)

- **Authoritative development source (this repository):** `iaa/` at the repo
  root is THE behavioral core (SKILL.md v3, sha256 `73f7b887…`; full table in
  `release-hardening/gate-2/00-semantic-freeze.md`). All edits happen here.
- **Deployed runtime source (derived output):** `$HOME/.local/share/iaa/` —
  written exclusively by `scripts/iaa deploy` (stage → byte-verify → swap →
  provenance record with rollback retained). Consumer symlinks in
  `~/.claude|~/.agents|~/.zcode /skills/iaa` keep pointing at the same path.
- **Package projections (derived outputs):** `packaging/{claude,codex,zcode}`
  and the eval dev-plugin skill copy — generated by `scripts/build-packages.sh`,
  never hand-edited, byte-parity enforced by `scripts/check-parity.sh` (CI).

The pre-Gate-2 procedure ("edit the live canonical file, then copy back into
git and hash-verify") is **retired**: editing the deployed tree directly is now
detectable drift (`iaa doctor` reports it), not the workflow.

## Editing procedure (current)

1. Edit the repository (`iaa/`, docs, packaging templates, `VERSION`).
2. `scripts/build-packages.sh` → refresh projections; `scripts/check-parity.sh`
   must pass.
3. Commit; then `scripts/iaa deploy` (repo → runtime source; provenance
   recorded) and, if packaged forms changed, update/reinstall the plugin.
4. `iaa doctor` → exit 0.
